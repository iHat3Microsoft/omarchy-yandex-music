# База знаний форка: Omarchy Yandex Music (Synced Lyrics & Gesture Controls)

Этот документ предназначен для разработчиков и AI-агентов в последующих сессиях. Он содержит полную информацию об архитектуре проекта, ключевых отличиях от апстрима, деталях реализации каждого коммита и правилах сборки/тестирования.

## 1. Контекст и происхождение

- **Апстрим:** `https://github.com/vornashev/omarchy-yandex-music.git`
- **Личный форк:** `https://github.com/iHat3Microsoft/omarchy-yandex-music.git`
- **Локальная рабочая директория:** `/home/chm0d777/Work/tries/2026-10-03-yamusic-waybar-lyrics`
- **Цель форка:** Перенос функционала из плагина для Waybar (`yamusic-waybar-lyrics`) в новую среду **Omarchy Quickshell (Qt 6 / QML)**:
  1. Синхронизированный караоке-текст (synced lyrics LRC) прямо в строке статус-бара.
  2. Управление жестами мыши (клики и колесо) без перегрузки бара кнопками плеера.
  3. Кнопка лайка (пустое/залитое сердце) прямо на панели бара.
  4. Плавные QML-анимации смены текста по кривым Безье.
  5. Визуальная индикация паузы на обложке трека (затемнение + анимированный значок паузы).
  6. Оптимизация производительности: локальный дисковый кэш текстов и предзагрузка соседних треков.

## 2. Архитектура системы

```
┌─────────────────────────────────────────────────────────────┐
│                       Omarchy Bar (Quickshell)              │
│                                                             │
│  [Cover / Pause] [♡ Like] [Artist — Title] │ [Synced Lyric] │
│         ▲                                         ▲         │
│         │                                         │         │
│    BarPlayer.qml ◄──────── WidgetLogic.qml ───────┘         │
│                                   ▲                         │
│                                   │ IPC (UNIX Domain Socket)│
│                                   ▼                         │
│                     ~/.local/bin/omarchy-yandex-music       │
│                                   ▲                         │
└───────────────────────────────────┼─────────────────────────┘
                                    ▼
┌─────────────────────────────────────────────────────────────┐
│                 omarchy-yandex-music.service                 │
│                                                             │
│  backend.py (Python 3 daemon)                               │
│   ├── Yandex Music API (yandex-music-api vendored wheel)    │
│   ├── Дисковый кэш текстов: ~/.config/.../lyrics/{id}.json  │
│   ├── Кэш URL и предзагрузка соседних треков (next/prev)    │
│   └── Управление mpv (IPC сокет, буферизация потока)        │
└─────────────────────────────────────────────────────────────┘
```

### Основные компоненты:
1. **`backend/backend.py`**: Демон на Python. Запускается как systemd user-сервис `omarchy-yandex-music.service`. Взаимодействует с API Яндекс Музыки через `yandex-music-api` и управляет процессом `/usr/bin/mpv` через сокет IPC.
2. **`bin/omarchy-yandex-music`**: Легковесный CLI-клиент на Python, отправляющий JSON-запросы демону через сокет `$XDG_RUNTIME_DIR/omarchy-yandex-music.sock`.
3. **`WidgetLogic.qml`**: Фоновый QML-компонент плагина. Выполняет периодический опрос состояния (`status`), инициирует загрузку текстов, управляет очередью действий (`actionQueue`) и монтирует всплывающее окно `Panel.qml`.
4. **`BarPlayer.qml`**: Визуальный виджет на статус-баре. Отображает обложку (с индикацией паузы), кнопку лайка, бегущую строку/название трека, разделитель и караоке-строку текста с интерполяцией таймкодов и плавной анимацией.

## 3. Детальный разбор коммитов форка

### Коммит 1: `0ae9cc7` — Добавление текстов, управления мышью и лайков
- **`BarPlayer.qml`**:
  - Убраны три кнопки управления (`󰒮`, `󰏤`/`󰐊`, `󰒭`), освобождено пространство на баре.
  - Добавлена кнопка лайка: иконка `󰋑` (залитое сердце) акцентным цветом при `liked == true`, либо `󰋕` (контур) при `liked == false`. По клику вызывает `root.logic.action("like")`.
  - Добавлена интерполяция времени воспроизведения: `displayPosition` пересчитывается таймером каждые 80 мс (`positionClockMs`).
  - Добавлен слот синхронизированного текста (`lyricsSlot`) с переходом по кривым Безье:
    - Старая строка плавно уходит вверх и затухает (`Easing.InQuad`, 120 мс).
    - Новая строка появляется снизу и встаёт в центр с кривой `Easing.OutCubic` (220 мс).
  - На область трека и текста установлена единая `playbackMouseArea`:
    - **ЛКМ**: Пауза / Возобновить (`action("pause")`).
    - **ПКМ**: Следующий трек (`action("next")`).
    - **СКМ**: Предыдущий трек (`action("previous")`).
    - **Колесо вверх**: Перемотка к следующей строке текста (или +5 сек).
    - **Колесо вниз**: Перемотка к предыдущей строке текста (или -5 сек).
    - Клик по обложке: Открытие/закрытие попапа плеера (`root.logic.toggle()`).
- **`WidgetLogic.qml`**:
  - Добавлена структура `lyricsData` и процесс `lyricsProcess` для вызова `cli lyrics`.
- **`README.md` / `README.ru.md`**:
  - Описаны ключевые отличия форка в шапке документации.

### Коммит 2: `a953739` — Обработка событий колеса мыши
- **`BarPlayer.qml`**:
  - Добавлено `wheel.accepted = true` в `playbackMouseArea.onWheel` для предотвращения перехвата события композитором Hyprland или родительскими виджетами бара.

### Коммит 3: `0877009` — Расширение слота текста и выравнивание по левому краю
- **`BarPlayer.qml`**:
  - Увеличена ширина слота для текстов: нормальная ширина увеличена с 250 до 420 px (широкий режим до 540 px), чтобы длинные строки не обрезались многоточием.
  - Текст внутри слота выровнен по левому краю (`anchors.left: parent.left`), чтобы караоке-строка начиналась сразу после разделителя `│`, сохраняя визуальную монолитность строки.

### Коммит 4: `455acdf` — Дисковый кэш, предзагрузка и очередь действий
- **`backend/backend.py`**:
  - Добавлен постоянный дисковый кэш текстов: `~/.config/omarchy-yandex-music/lyrics/{id}.json`. Загруженные тексты сохраняются на диск и при повторном воспроизведении трека отдаются мгновенно без сетевых задержек (0 мс).
  - Реализован механизм `_prefetch_adjacent_tracks()`: при запуске трека в фоновом потоке автоматически предзагружаются прямые ссылки на аудио и тексты для следующего (`index + 1`) и предыдущего (`index - 1`) треков, а также прогревается TCP/TLS-соединение к CDN Яндекса (загрузка первых 128 КБ аудиопотока). Переключение треков стало практически мгновенным.
  - Настроен внутренний буфер `mpv`: добавлены флаги `--demuxer-max-bytes=32M` и `--demuxer-readahead-secs=30`.
  - Метод `status()` теперь сразу включает поле `lyrics` в ответе статуса, устраняя необходимость постоянного запуска сторонних процессов.
- **`WidgetLogic.qml`**:
  - Реализована очередь действий `actionQueue`: быстрые клики и прокрутка колеса мыши больше не отбрасываются, если предыдущая команда ещё выполняется.

### Коммит 5: `Индикация паузы на обложке`
- **`BarPlayer.qml`**:
  - На обложку добавлен оверлей затемнения `pauseDimmer` (`opacity: 0.45` черного цвета) с плавной анимацией `Behavior on opacity` (180 мс, `Easing.OutCubic`).
  - Поверх обложки добавлен центрированный значок паузы `󰏤` белого цвета с плавной анимацией прозрачности и лёгкого масштабирования (`scale: 0.75 -> 1.0`, `Easing.OutBack`).
  - Когда воспроизводится музыка — обложка чистая и яркая; при паузе — плавно затемняется с видимым бейджем паузы.
  - Если для трека есть синхронизированный текст, но идёт вступление/проигрыш — в слоте текста отображается ненавязчивый символ `♪`.

## 4. Конфигурация и пути в системе

| Путь | Назначение |
|---|---|
| `~/.config/omarchy/plugins/vornashev.yandex-music/` | Активная директория плагина в Omarchy shell |
| `~/.config/omarchy/shell.json` | Конфигурация статус-бара Omarchy (порядок виджетов) |
| `~/.config/omarchy-yandex-music/` | Директория данных сервиса (права 0700) |
| `~/.config/omarchy-yandex-music/token.json` | Сохранённый токен Device OAuth |
| `~/.config/omarchy-yandex-music/lyrics/` | Дисковый кэш текстов песен `{track_id}.json` |
| `~/.local/share/omarchy-yandex-music/backend.py` | Рабочий исполняемый файл демона сервиса |
| `~/.local/bin/omarchy-yandex-music` | CLI-утилита IPC |
| `~/.config/systemd/user/omarchy-yandex-music.service` | Пользовательский systemd юнит |

## 5. Инструкции по тестированию и верификации

### Запуск unit-тестов Python (все 82 теста должны проходить успешно):
```bash
uv run --with ./vendor/yandex_music-3.1.0b2-py3-none-any.whl --with requests --with dbus-next python3 -m unittest discover -s tests -p "test_*.py"
```

### Проверка синтаксиса QML (qmllint):
```bash
qmllint BarPlayer.qml WidgetLogic.qml
```

### Перезапуск сервиса и оболочки при внесении изменений:
```bash
# 1. Скопировать измененные файлы в рабочий каталог плагина
cp BarPlayer.qml WidgetLogic.qml ~/.config/omarchy/plugins/vornashev.yandex-music/
cp backend/backend.py ~/.config/omarchy/plugins/vornashev.yandex-music/backend/backend.py
cp backend/backend.py ~/.local/share/omarchy-yandex-music/backend.py

# 2. Перезапустить бэкенд и шелл
systemctl --user restart omarchy-yandex-music.service
omarchy restart shell
```

## 6. Правила безопасности и конфиденциальности

1. **Никогда не читать и не передавать в контекст:** `~/.bashrc`, `YANDEX_TOKEN`, `YANDEX_USER_ID`. Авторизация плагина работает изолированно через файл `~/.config/omarchy-yandex-music/token.json`.
2. **Никогда не трогать и не затирать:** локальный репозиторий `yamusic-waybar-lyrics` в домашней папке.
3. **Пушить только в личный форк:** `git@github.com:iHat3Microsoft/omarchy-yandex-music.git`, не отправлять pull request в апстрим без прямого запроса пользователя.
